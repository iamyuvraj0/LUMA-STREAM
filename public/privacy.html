TRANSPARENCY FIRST

Privacy & analytics.

STREAM SUNAA uses privacy-minimised analytics to understand how the site is used and to improve the browsing experience. Visitors do not need an account.

What analytics records

A random browser ID stored in local storage; internal page path and page title; a broad device class; and, when the browser exposes it, a device model hint. The server also derives a browser and operating-system label from the request's user-agent header, but does not store the full header string.

Approximate location

The server uses the visitor's public IP address transiently to request an approximate city, region and country from IPWho.is. The raw IP address is not written to the visitor analytics database. The geolocation provider receives the queried IP address and may process it under its own terms and privacy policy. IP-based locations can be wrong, especially for VPNs, proxies, mobile networks and shared connections.

What we do not collect

The analytics dashboard does not request GPS coordinates, camera or microphone access, real names, account credentials, or the contents of a visitor's device. The dashboard cannot prove that a third-party embedded player is actively playing video; it records the page the browser is visiting.

Retention and controls

Visitor history is stored in the site's configured PostgreSQL database until the site operator removes it. A browser ID can be removed by clearing this site's local storage, which will cause the site to issue a new anonymous ID on a later visit. You can also opt this browser out below. Analytics may be unavailable if the site's database or geolocation lookup is offline.
